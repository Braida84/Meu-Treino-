COMO ATUALIZAR NO GITHUB PAGES
1. Descompacte este ZIP.
2. No repositório "meu-treino", substitua os arquivos antigos pelos arquivos deste pacote.
3. Aguarde o GitHub Pages publicar.
4. No POCO X6 Pro, feche e reabra o app.
5. Se continuar aparecendo a versão antiga, Chrome > Configurações > Configurações do site > seu site > limpar dados; depois instale novamente.

CONEXÃO XOSS X2
1. Vista a cinta e umedeça os eletrodos.
2. Ligue o Bluetooth do celular.
3. Abra o app via HTTPS no Chrome/PWA.
4. Toque em "Conectar XOSS X2".
5. Escolha a cinta na janela do Android.
6. Não é necessário parear antes nas configurações do Android.
7. Se outro app estiver usando a cinta via Bluetooth, feche-o antes do teste.

Observação: Web Bluetooth exige HTTPS e navegador compatível. O registro cardíaco deste app não é ferramenta médica.
